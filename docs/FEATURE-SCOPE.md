# 功能范围

## 不需要

### 信息与显示

- `A4` 玩家血量、武器、护甲信息
- `A10` 手雷、爆炸物提示
- `A11` 门、钥匙卡读卡器、车辆提示
- `A13` 可穿透/不可穿透部位标记

### 地图与导航

- `B2` 小地图雷达
- `B3` 雷达上的玩家、Boss、Scav 和撤离点
- `B5` 指南针和坐标
- `B6` 雷达范围、缩放和透明度

### 生存与移动

- `C5` 无碰撞
- `C6` 自定义移动速度
- `C7` 自由镜头
- `C9` 扩大交互距离

### 武器与战斗

- `D1` 无后坐力
- `D2` 无武器摆动
- `D3` 无限弹药
- `D4` 武器强制全自动
- `D5` 武器最大耐久
- `D7` 穿墙射击
- `D8` 快速投掷
- `D9` 命中标记
- `D10` 自定义准星
- `D12` 热成像

### 世界与生成

- `E5` 迫击炮打击
- `E6` 生成 Bot
- `E7` 生成任务物品
- `E8` 生成藏身处物品
- `E9` 生成任意物品
- `E10` 全物品已检视

## 需要

除上方明确排除项外，其余已列功能全部保留，包括：

- 玩家/Scav/Boss ESP、阵营颜色、骨架、战利品、价格、容器、任务物品、撤离点、可见性判断
- 全屏地图、任务地点
- 耐力、生命、水分能量、负面状态、传送、坠落伤害
- 武器故障保护、瞄准辅助
- 时间、天气、空投、火车
- 菜单、快捷键、中文、配置保存、预设、单项开关、控制台、日志
- `G1`–`G8` 安装器改进

## 当前实现状态

`G1`–`G8` 已在 Installer 3.3.0 中实现并通过本地测试。

其余游戏功能属于新的 EFT 1.3 IL2CPP 插件工程，旧 `NLog.EFT.Trainer.dll` 不能直接用于当前版本。
